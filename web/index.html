CLI reference

# Trace a message by initiating tx hash
superchain-trace trace 0xabc123... --chain base

# Check message safety level
superchain-trace status 0xdef456... --chain op

# List supported chains
superchain-trace chains

# JSON output for agent consumption
superchain-trace trace 0xabc... --format json
This dashboard is a teaching simulator — the real tool queries OP-Supervisor and chain RPCs. Install the CLI: cargo install --git https://github.com/kcolbchain/superchain-trace. Integration tests with supersim are tracked in issue #1.
